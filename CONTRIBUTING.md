# Contributing to KAI AI Removes

Thank you for helping improve a private, browser-local media utility.

## Principles

- Keep image and video processing local by default.
- Do not make misleading claims about restoration quality.
- Keep the responsible-use notice visible.
- Keep the **Created by KAI AI** credit visible.
- Preserve accessibility and mobile-friendly layout.
- Do not add analytics, trackers, uploads, or hidden network requests.

## Development

```bash
npm run start
npm run check
```

Test video changes in a recent desktop Chrome or Edge browser. Include a short, self-created test clip and verify that the output duration, dimensions, and selected region are correct.

Do not submit copyrighted calibration assets, third-party branding, private user media, or code from incompatible licenses.
