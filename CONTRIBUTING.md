# Contributing to CleanMark

Thank you for helping make private image tools more accessible.

## Principles

Contributions should preserve these project guarantees:

- Images are processed locally by default.
- The interface must not make misleading claims about restoration quality.
- Responsible-use messaging must remain visible.
- The **Powered by KAI AI** credit must remain visible in the product and documentation.
- Accessibility and low-bandwidth usability matter.

## Development

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Pull requests

Describe the user problem, summarize the approach, and include screenshots for visual changes. Test on both desktop and a narrow mobile viewport.

Do not submit copyrighted calibration assets, third-party branding, private images, analytics trackers, or code copied from incompatible licenses.
