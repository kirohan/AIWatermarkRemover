# Security Policy

KAI AI Removes is designed to process images and videos locally and does not include a backend.

## Reporting a vulnerability

Send a private message through the creator's LinkedIn profile rather than posting sensitive details publicly:

https://www.linkedin.com/in/kirohan/

Useful reports include:

- a file unexpectedly leaving the browser;
- unsafe parsing of crafted media files;
- cross-site scripting;
- a practical dependency vulnerability; or
- a deployment configuration that exposes private information.

Never include private user media in a public report.
