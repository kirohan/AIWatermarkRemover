# Security Policy

CleanMark is designed to process images locally and does not include a backend.

## Reporting a vulnerability

Open a private GitHub security advisory in the repository rather than a public issue when reporting a security-sensitive problem.

Useful reports include:

- a file unexpectedly leaving the browser;
- unsafe parsing of crafted image files;
- cross-site scripting;
- dependency vulnerabilities with a practical exploit path; or
- a deployment configuration that exposes private information.

Never include private user images in a public issue.
